# Cells that sense. And compute.

An interactive educational exhibit about programmable whole-cell biosensors.

Live exhibit: https://Aprde.github.io/programmable-cell-exhibit/

Release: local-1791168527807 (2026-10-05).

The current desktop exhibit has 32 manual lecture stops. Use Play next step to move smoothly to the next hold, or use the mouse wheel at any time to take manual control. The final pullback animation continues during HOLD, and the three contributors are shown directly.

This repository contains the deployable static website, including locally hosted illustrations, videos and fonts. No installation or sign-in is needed to view it.

Research reference: https://doi.org/10.1021/cbe.5c00015

Font licenses are included beside their font files.
